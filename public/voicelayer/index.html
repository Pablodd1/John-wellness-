Universal Handoff Architecture

Why VoiceLayer is 10× faster and 80% cheaper to run than raw LLM voice agents.

Sending every spoken word ("scroll down", "update", "how much is this?") through a frontier LLM audio stream costs $0.15+/minute and adds 800ms of lag. VoiceLayer uses a 3-Tier Universal Handoff pipeline.

TIER 0 • ~75% OF TRAFFIC < 10ms • $0.00

Deterministic Local Bypass

Executes directly inside the browser with zero network round-trip. Handles navigation, scrolling, cart inspection, price/stock checks, deictic commands (“add this one”), and the 5-stream executive briefing (“update”).

→ "update" → Briefing.summaryLine()
→ "how much is whey" → Inventory.query()
→ "scroll down" → window.scrollBy()
TIER 0.5 • ~15% OF TRAFFIC ~120ms • Allowlisted

Jev System One Classifier

When a user speaks colloquially or in another language, TypeSafe Jev classifies the utterance strictly into one of 28 allowlisted UI actions and evaluates the noul safety score. The model never receives raw DOM execution authority.

→ Input: colloquial / multilingual
→ Guardrail: if (noul ≥ 0.30) block()
→ Output: ALLOWLISTED_UI_ACTIONS[i]
TIER 1 • ~10% OF TRAFFIC Grounded RAG + Neural TTS

Context-Grounded Cloud Brain

For open-ended domain questions, VoiceLayer sends a compact JSON snapshot of the live page, catalog, and profile to DeepSeek V3.2, xAI Grok, Gemini 2.5 Flash, OpenAI, or Claude—speaking the answer via Grok Voice 3.0 or Deepgram Aura-2.

→ Context: VL.contextSnapshot()
→ Linter: CP_LINT (No Rx / Diagnosis)
→ Voice: Grok Voice 3.0 / Aura-2

Developer Integration

Drop in 1 script tag. Symbiosis handles the rest.

VoiceLayer works immediately on any static HTML, React, Next.js, Vue, Shopify, or Webflow site. With zero configuration, it scans your DOM headings, buttons, and product cards. When you pass a window.__VOICELAYER_SYMBIOSIS__ object, it unlocks personalized briefings, dual calendars, and custom host actions.

1. Zero-Config DOM Mode

Paste the script tag. VoiceLayer scans visible buttons, links, prices, and headings automatically.

2. Symbiotic Handshake Mode

Pass profile, calendar, workCalendar, toTake, toBuy, and actions via JS or JSON script tag.

3. Cloud Edge Ready (Vercel & Cloudflare)

Stateless edge API routes (/api/voice/*) keep your Deepgram, Grok, and LLM keys 100% server-side.
